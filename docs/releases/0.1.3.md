# Hexora 0.1.3

Released October 17, 2026. Changes since
[Hexora 0.1.2](https://github.com/ZENINXOP/Hexora/releases/tag/v0.1.2).

## Download

- **Hexora.0.1.3.apk** is the main app. The other APK assets are optional tool
  packs, which the app downloads when requested.
- Package `com.hexora.zenin`, version code 14, Android 4.4+; target SDK 28.
- Signed with the existing Hexora release certificate. Updates 0.1.2 in place.
  Debug builds use a different certificate and cannot be updated directly.
- Verify the APK with `Hexora.0.1.3.apk.sha256` or `SHA256SUMS`.

## Appearance

- New owner-supplied black folder, white/blue H and Android artwork for the
  launcher, About screen and repository README. Includes legacy, adaptive and
  Android themed-icon assets.
- Yellow file-list folder icons are now black, with a fine outline for
  visibility in light, dark and black themes.

## Files, storage and editor fixes

- Add local storage through Android's folder picker, including folders exposed
  by other apps. Saved grants remain subject to provider/system permissions.
- Normal rename uses direct filesystem access and saved folder grants before
  Shizuku/root. Access failures have clearer messages.
- Fix opening Rename for names ending in a dot, including `app.apk.`.
- Replace / Keep both / Cancel for file-operation conflicts, including copying
  an item into its current folder. Replacing the identical source is a safe
  no-op; Keep both creates a numbered copy. Failed replacements restore the
  previous destination or report the retained recovery path.
- Faster local transfers, immediate rename-based moves where possible,
  verification before copy-based source deletion and safer bulk-rename recovery.
- Temporary shared imports are cleaned after use and after interrupted sessions,
  with active editing/background work protected.
- Bracket-pair highlighting follows the caret. Tapping a hidden operation's
  notification restores its progress dialog.
- Quick-edit icon handling, split-bundle icons, package/data storage details,
  Xiaomi backup opening, video-folder navigation and same-panel comparisons
  include the fixes committed after 0.1.2.

## Tool packs

- Validate the APK's actual version code instead of a stale Java constant.
- Unique download filenames, cleanup after failure, readable errors and
  safer update rollback. Cached catalog corrections preserve checksum checks.
- First-party Device, Network, Media, Text, Notes and Random packs are version
  1.1/code 2; Math is version 1.6/code 6. They are signed with Hexora's release
  key and pinned by SHA-256 in the bundled and published catalogs.
- Catalog refresh uses this repository, verifies its detached RSA/SHA-256
  signature and starts a separate Hexora catalog cache. Previous upstream
  catalog cache entries do not override the new first-party release.
- In-app app-update checks now use `ZENINXOP/Hexora`.

## APK signature tools

- Replace the LSPatch dialog options with an independent Java Parcel certificate
  runtime, while retaining the lightweight Java reference rewriter.
- The runtime saves a separately signed APK, preserves original DEX entries and
  keeps the original Application lifecycle. Its output requires Android 9+.
- Native APK reads, packed loaders, final/inaccessible Application classes,
  original Application static-initializer checks, multiple/rotated signers,
  platform checks and server checks remain unsupported. Compatibility varies.
- Research reference and dependency attribution are in the bundled notices.
  This is not MT Manager's proprietary implementation or a claim of parity.
