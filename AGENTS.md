# Hexora working preferences

- Keep changes local. Do not push to GitHub unless the user explicitly asks
  to push; repository connection and edit requests do not authorize a push.
- Do not run builds, compilation, or APK packaging unless the user explicitly
  asks to resume building. Continue source, icon, and UI edits without building.
- Support both light and dark themes.
- Match MT Manager using screenshots supplied by the user; do not claim exact
  visual parity before comparing against those references.
- Preserve upstream attribution and license notices, and credit OpenAI Codex
  for AI-assisted contributions.
- Include `Co-authored-by: Codex <codex@openai.com>` in commits for work assisted
  by Codex, as requested by the project owner.
