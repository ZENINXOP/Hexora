# Hexora bug sweep — October 11–12, 2026

AI-assisted implementation and validation: OpenAI Codex. Changes remain local.
MuMu stays visible at the owner's request; tests target `127.0.0.1:16384` only.

## Fixes

- Returning from an editor or refreshing an archive keeps the active filter.
  The filter input and visibility follow the selected pane, and closing the
  filter in one pane does not clear the other pane's query.
- Archive folder sorting now uses the same archive-plus-entry-path preference
  key when saving and loading. Two archives with a `docs/` folder keep separate
  sort settings.
- Reloading a dirty text file asks before discarding unsaved changes. Cancelling
  leaves the buffer and original file intact.
- Editor results retain every saved archive entry, including entries in closed
  tabs. Pending archive saves survive rotation and minimized session restoration.
  Opening local files and class previews also retains a result path to the
  browser; a minimized editor is reused instead of creating another editor.
- Ordinary ZIP/JAR/AAR text edits do not offer APK signing. APK detection is
  case-insensitive, and signed staged APKs publish optional V4 `.idsig` files
  under the destination's name.
- Archive document updates validate the full batch, modify a sibling staging
  file, sign it if required, preserve an unused original backup, and replace the
  archive only after preparation succeeds. A missing explicit source is an
  error rather than permission to update a different open archive. Publication
  is atomic per archive; multiple archives and an APK's V4 sidecar are separate
  publications. A V4 sidecar failure reports that the APK has already been saved.
- APK alignment now removes legacy raw zero padding before writing structured
  extra-field records, preserving valid metadata. This avoids corrupt central
  directory extras after editing and resigning an existing APK.
- Moving an entry from ZIP to a regular folder waits until the source removal
  completes before refreshing the browser.
